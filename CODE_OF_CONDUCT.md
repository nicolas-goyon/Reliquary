# Code of conduct

Reliquary follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The full text of the Contributor Covenant applies to all project spaces: issues, pull requests, discussions and reviews.

## Rules in short

- Be respectful and kind to all people.
- Give and accept constructive criticism.
- Do not harass, insult or attack people.
- Do not publish private information about other people.

## Report a problem

Contact the maintainer, [@nicolas-goyon](https://github.com/nicolas-goyon), with the contact information on the GitHub profile.
The maintainer reads each report and keeps the identity of the reporter private.
