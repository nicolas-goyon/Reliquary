# Public decks

This file describes how a user explores the public decks.
Terms follow the [glossary](../glossary.md).

## Exploration

- A user can search public decks by format, commander, colors, card in the deck, archetype, date and popularity.
- Reliquary has author profiles and favorites, and a user can follow an author.
- A user can duplicate a public deck into their own decks.
  The copy keeps a link to the original deck.
  The [duplication rules](./deck-building.md#duplication) apply.
