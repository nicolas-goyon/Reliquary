# Specification

This folder contains the product specification of Reliquary.
This file lists the files of the specification.
Terms follow the [glossary](../glossary.md).

## Files

Eight feature areas form the core of Reliquary, and each feature area has its own file.
Each feature area makes its data and its events available to plugins and modules.

- [Overview](./overview.md) gives the summary, the name, the vision, the license, the users, the deck and collection rules, and the scope decisions.
- [Deck building](./deck-building.md) describes card search, deck editing, tags, categories, auto-tag, purchase preferences, assembled decks and duplication.
- [Deck testing](./deck-testing.md) describes the four test modes and the table engine that they share.
- [Public decks](./public-decks.md) describes the search of public decks, the author profiles and the duplication of public decks.
- [Deck organization](./deck-organization.md) describes folders, deck tags, sort, filters and group actions on decks.
- [Deck analysis](./deck-analysis.md) describes the analysis of a deck for all formats, with Commander first.
- [Versions and variants](./versions-and-variants.md) describes deck versions, variants, comparisons, transition plans and merges.
- [Collection](./collection.md) describes the detail level, locations, movements, inventories, collection sharing, and import and export.
- [Multi-face cards](./multi-face-cards.md) describes cards with more than one face or more than one name.
- [Cross-cutting features](./cross-cutting-features.md) lists the features that users expect everywhere, with their priority and their [milestone](../roadmap.md).
