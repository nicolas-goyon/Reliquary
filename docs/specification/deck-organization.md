# Deck organization

This file describes how a user organizes their decks.
Terms follow the [glossary](../glossary.md).

## Organization features

- A user can organize decks in nested folders, add deck tags, pin decks and archive decks.
- A user can sort and filter the deck list with these criteria:
  - format
  - colors
  - date
  - assembled deck or not
  - completeness against the available cards
- A user can move, tag or export several decks with one group action.
