# NNNN. Title of the decision

- Status: Proposed
- Date: YYYY-MM-DD
- Deciders: the GitHub logins of the deciders, for example @nicolas-goyon

## Context

Describe the question that the decision answers.
Give the facts that limit the options: requirements, constraints and earlier decisions.
Give the options, with their advantages and their disadvantages.

## Decision

Give the decision in the active voice, for example: "The API uses SignalR for real time."
Use a list when the decision has more than one part.

## Consequences

Give the results of the decision: the advantages, the disadvantages and the new work.
