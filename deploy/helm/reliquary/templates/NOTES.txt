Reliquary {{ .Chart.AppVersion }} is installed in the namespace {{ .Release.Namespace }}.

The site is the Service {{ include "reliquary.fullname" . }}-web on port {{ .Values.web.service.port }}.
Send all the paths of {{ .Values.config.publicUrl }} to this Service.

To check the instance without a route, run these commands:

  kubectl --namespace {{ .Release.Namespace }} port-forward service/{{ include "reliquary.fullname" . }}-web 8080:{{ .Values.web.service.port }}
  curl http://localhost:8080/api/v1/status

The guide: https://nicolas-goyon.github.io/reliquary/deployment/kubernetes/
