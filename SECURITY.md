# Security policy

## Supported versions

Reliquary has no release yet.
Security corrections go to the `develop` branch.

## Report a vulnerability

Do not open a public issue for a vulnerability.
Use the private report function of GitHub:

1. Open the [Security tab](https://github.com/nicolas-goyon/reliquary/security) of the repository.
2. Select "Report a vulnerability".
3. Describe the problem, the affected version or commit, and the steps that show the problem.

The maintainer answers in the private report.
After the correction, the maintainer publishes a security advisory.
